# Join (Frontend)

## Join was a group project to create a task management application for managing categories, tasks, subtasks and users. It provides CRUD operations for tasks and user authentication.<br/>
It's build with JavaScript, CSS and HTML.

You can user this project with the Join-Backend.

## How to install this repository (Frontend):

1. Clone this repository:
```
    git clone <GitHub repository link>
```

2. Start the local liveserver (on path: 127.0.0.1:5500)
